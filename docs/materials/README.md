# 项目资料目录

本目录只保存会直接影响实现与验证的项目资料，不做大而全归档。

## 目录约定

- `board_reference.md`
  - 板卡官方真源摘录
  - 仅保留引脚、器件、bring-up 相关要点
- `bringup_decisions.md`
  - 当前工程对板级初始化、组件拆分、阶段优先级的决策记录
- `current_stage_audit.md`
  - 当前代码阶段 vs 构建/上板验收阶段的审计结论
  - 用于区分“代码已接入”与“真正达到手测准入”
- `navigation_bridge_protocol.md`
  - 手机侧导航 BLE 桥接协议
  - 单包 / 分片发送规则与对接约束
- `amap_navigation_adapter.md`
  - 高德导航 `NaviInfo` 到仓库统一导航事件的字段对齐说明
  - 常见 `iconType` 到固件转向枚举的收敛映射
- `verification/`
  - 后续阶段的串口日志、照片、录屏或测试备注

## 使用原则

- 优先记录“会影响代码实现”的事实，而不是产品宣传描述
- 每条结论尽量指回官方来源
- 若资料与实测不一致，以实测为准，并在对应文档追加差异记录
