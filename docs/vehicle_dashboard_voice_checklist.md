# 车载仪表 + 语音交互验收清单

## P0 手测准入清单

- [ ] `idf.py build` 通过
- [ ] 设备正常启动，无重启循环
- [ ] 屏幕可显示启动页
- [ ] 触摸输入可产生事件日志
- [ ] RTC 可读取到有效时间
- [ ] System 页面可显示时间、连接状态占位、电量占位
- [ ] 左右滑动或按键可切换基础页面

## P1 手测准入清单

- [ ] QMI8658 初始化成功
- [ ] 250Hz 原始数据读取稳定，无持续 I2C 错误
- [ ] roll/pitch 数值变化方向正确
- [ ] 静止时角度抖动在可接受范围内
- [ ] 姿态页刷新主观平滑
- [ ] 页面切换后返回姿态页仍可持续更新

## P2 手测准入清单

- [ ] 麦克风采集可用
- [ ] 喇叭播放可用
- [ ] 语音唤醒可触发状态变化
- [ ] 语音激活时自动进入 Page 5
- [ ] 语音结束后恢复到先前页面
- [ ] 语音期间 UI 不出现明显卡死

## P3 手测准入清单

- [ ] 手机端成功连接设备 BLE 服务
- [ ] 模拟导航数据包可被设备解析
- [ ] 导航页显示箭头、距离、路名
- [ ] 新导航数据到达时可自动切页
- [ ] 导航停止 10 秒后可自动回退
- [ ] 异常长度路名不会导致崩溃

## P4 手测准入清单

- [ ] 设备成功连接 ELM327
- [ ] RPM 可读取并更新
- [ ] 车速可读取并更新
- [ ] 水温可读取并更新
- [ ] OBD 页显示数值与仪表状态
- [ ] ELM327 断开后系统可恢复，不出现死锁

## P5 手测准入清单

- [ ] 语音与导航切页优先级符合设计
- [ ] OBD 告警可触发提示
- [ ] 电量百分比显示稳定
- [ ] 30 秒无操作后背光降低
- [ ] 2 分钟无操作后进入轻睡眠
- [ ] 唤醒后系统可恢复页面与关键状态

## 通用异常清单

- [ ] 任一 I2C 设备掉线时系统不会直接崩溃
- [ ] BLE 手机未连接时导航页显示空态
- [ ] OBD 未连接时 OBD 页显示空态
- [ ] Wi-Fi 不可用时语音模块能给出失败状态
- [ ] 页面频繁切换时无明显内存泄漏

## 日志证据要求

每个阶段至少保留以下一种验证证据：

- [ ] 串口日志片段
- [ ] 屏幕实拍照片或录屏
- [ ] 对应阶段的测试备注

## 当前建议的下一步验收目标

当前开发机仍缺少 `idf.py`，建议在具备 ESP-IDF 环境后先把 P0 + P1 的最小验收跑通，目标压缩为：

- [ ] 工程可编译
- [ ] 屏幕亮起
- [ ] System 页面显示
- [ ] RTC 时间可读
- [ ] 页面切换链路成立
- [ ] QMI8658 初始化成功
- [ ] 姿态页和指南针页能显示实时数值
